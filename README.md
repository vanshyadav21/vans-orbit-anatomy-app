🪐 VANS-Orbit // 軌道 — Brutalist Streetwear App

A dark brutalist, cyberpunk-inspired streetwear e-commerce web application inspired by the design language of Zenin Clan and GangRage. Built with a stark monochrome and crimson aesthetic, realistic bunker blast-gate entry animations, interactive audio synthesis, and an interactive fit builder.

⚡ Highlights

🚪 Bunker Vault Entry Sequence: Interactive blast doors with hydraulic steam release, screen tremors, and Web Audio gear sounds.

🎨 Dark Brutalist Aesthetics: High-contrast jet black (#070709), stark white typography, industrial slate grey steel textures, and crimson red (#FF1744) accents.

🎛️ Audio Drone & SFX: Synthesizer sub-drone and mechanical tactile click effects powered by the Web Audio API (with on/off controls).

🥋 Interactive 3D Fit Builder: Mix and match upper armor, cargos, and tactical gear with real-time GSM fabric weight calculation.

🛒 Full E-Commerce Flow: Slide-out cart drawer, dynamic free-shipping progress tracker, promo code system (ORBIT10), and quick-view modals.

📺 CRT Scanlines Mode: Retro futuristic display filter toggle.

🛠️ Tech Stack

Frontend: HTML5, Vanilla JavaScript (ES6+)

Styling: Tailwind CSS (Utility classes + Custom Keyframes)

Audio Engine: Web Audio API (Pure synthesized oscillators & noise buffers)

Icons: Lucide Icons

🚀 Quick Setup

No dependencies or build steps required.

Clone the repo:

git clone https://github.com/your-username/vans-orbit.git
cd vans-orbit


Launch:

Double-click index.html to open in any modern browser, or

Use VS Code Live Server, or run:

python3 -m http.server 8000


Visit http://localhost:8000.
